# Human Text Studio

AI가 작성한 듯한 한국어와 영어 문서를 더 자연스러운 문체로 다듬는 정적 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 서버나 설치가 필요하지 않습니다.

## 기능

- 한국어/영어/자동 감지 언어 선택
- 원문 붙여넣기와 수정본 비교
- 자연스러운 문서, 비즈니스, 에세이, 캐주얼 톤 선택
- 인간화 강도 조절
- 과한 표현 줄이기, 문장 리듬 바꾸기, 연결감 추가 옵션
- 글자 수 표시, 예시 입력, 수정본 복사
- 한국어와 영어를 모두 반영한 앱 내부 자동 AI 문체 가능성 점수
- 탐지 신호와 문장별 위험 표시
- GPTZero, Originality.ai, Scribbr, QuillBot, Copykiller 검사 사이트 열기

## 현재 범위

이 버전은 API 없이 동작하는 규칙 기반 MVP입니다. 실제 LLM API를 붙이면 문맥 단위 재작성, 문서 유형별 프롬프트, 표절/AI 탐지 회피가 아닌 품질 중심의 문체 개선 흐름으로 확장할 수 있습니다.

AI 탐지 사이트는 대부분 자동 제출을 허용하지 않거나 로그인이 필요할 수 있어, 앱 내부에서는 규칙 기반 자동 점수를 먼저 보여주고 공식 사이트는 새 탭으로 여는 방식으로 연결합니다.
